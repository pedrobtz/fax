# fax: Facts About the Host, Container and Runtime

Reports facts about the operating system, hardware, virtualization,
containers, 'Kubernetes' pods, 'Azure', and the 'R' and 'Python'
runtimes. Reports the CPU and memory the current process can actually
use under 'cgroup' limits and CPU affinity, side by side with host
values, so thread pools and memory budgets can be sized correctly inside
containers. Also lists installed system, 'R' and 'Python' packages, and
provides a cheap CPU and memory usage probe for log messages. Pure 'R',
no network access unless explicitly requested.
